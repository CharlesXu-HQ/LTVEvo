Spec: `docs/specs/2026-10-04-ltv-agent.md`.

1. **Project skeleton and task contract.** Add `pyproject.toml`, package, example task, and data contract. Verify a task rejects overlapping label windows and mismatched raw-data hash.
2. **Full-data retail adapter.** Read the complete Online Retail II workbook, build customer/date snapshots and exclusion counts. Verify a transaction at an observation boundary is never a feature for that snapshot; all label windows are mature.
3. **Predictors and evaluator.** Add historical baseline and PyTorch candidate interface, MAE/RMSE/ranking/calibration diagnostics, and customer-cluster paired bootstrap. Verify known expected values and no CUDA fallback when GPU is required.
4. **Agent loop and isolation.** Port provider and journal patterns, add code proposals, Docker evaluation, bounded search, dataset-bound experience, anomaly review, and finalization. Verify test labels never enter proposal context and repeat runs resume.
5. **CLI and release documentation.** Add prepare, baseline, search, finalize commands plus English/Chinese README, data acquisition instructions, and Apache-2.0 license. Run unit tests and complete the full Online Retail II workflow on the target GPU when access permits; record exact data rows, device, metrics, and limitations.

Implementation is limited to fixed-horizon value prediction and ranking. Probability, time-to-event, additional datasets, and marketing intervention optimization can follow as separate tasks.
